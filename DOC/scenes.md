# 다섯 장면 — 구현 기획

> 시작 2026-11-23 저녁. 출발점은 브리프 ★-6 창업자 원문: 아침 일찍 일어나기 · 밤에 잘 자기 · 운동과 소모 칼로리 · 오늘 먹은 칼로리 · 일정을 가볍게. "성공한 사람들이 정해놓은 방법을 그대로 가져와 조합하고, 간편하고 세련되게, AI로 지속가능하게."
> 표기: **[결정]** 창업자 · **[제안]** Claude · **[고민 중]** · ⚠️ 빈틈. 아래는 전부 [제안]이고, 창업자가 한 장면씩 확인하면 [결정]으로 바꾼다.
> 규칙: 개발은 이 문서가 한 장(one-pager.md)으로 접히기 전까지 시작하지 않는다.

## 0. 하루는 한 바퀴다 [제안]

다섯 장면은 목록이 아니라 **순환**이다. 밤이 아침을 만들고, 아침이 하루를 만들고, 하루가 밤을 만든다.

```
밤 (잘 자기)  →  아침 (일찍 일어나기)  →  일정 (오늘 가볍게)  →  운동 · 식사 (칼로리 수지)  →  밤
```

- 폰이 하는 일은 장면마다 **하나의 화면, 하나의 동작**. 채팅 없음, 대시보드 없음.
- **[결정 2026-11-23] 애플 AI(Apple Intelligence·온디바이스 모델)는 쓰지 않는다.** AI는 우리 쪽에서 돈다 → 폰 세대 제한 없음(iOS 26, iPhone 11 이후 전부), 비용은 배치형이라 예측 가능. **AI가 하는 일 목록은 맨 마지막에**(화면·흐름이 먼저). 아래 장면 표의 "AI가 뒤에서" 줄은 자리 표시.
- AI가 하는 일은 **밤에 생각하고 낮에 보여주기**. 밤에 내일 한 바퀴를 미리 준비해 두고(기상 시각·첫 할 일·세 가지 일·운동·칼로리 예산·취침 시각), 낮에는 시스템 트리거(시간·실드·위젯)가 미리 만든 것을 꺼낸다. iOS 제약(research/ios-feasibility.md D-3)과 정확히 맞는 형태.
- "지속가능"의 뜻: 사람들이 못 하는 건 시작이 아니라 **계속**. AI의 일은 매일 밤 내일을 다시 맞춰주는 것(어제 못 했으면 오늘은 더 작게, 잘 됐으면 그대로).

## 1. 장면별 기획

### 1-1. 밤 — 잘 자기 ("인스타로 너무 많은 낭비를 해")

| | 내용 |
|---|---|
| 성공한 사람들의 방법 (후보) | **디지털 선셋**: 취침 1시간 전 화면 끝. **고정 취침 시각**(기상 목표에서 역산). 침실에 폰 두지 않기. 수면 루틴(조명·샤워·독서). |
| 폰이 하는 일 | 취침 1시간 전부터 인스타·숏폼·유튜브가 **조용해진다**(Screen Time 실드). 실드 화면에는 "내일 아침 ○○를 위해"(밤에 AI가 쓴 한 문장) + 버튼 "오늘 끝". 잠금화면 위젯이 "오늘 끝 · 기상 6:30" 상태를 보여준다. |
| AI가 뒤에서 | ~~기상 목표에서 취침 시각을 역산~~ → 취침·선셋 시각은 **사용자 설정(수면 시간 + 기상 시각)에서 계산**, AI 아님 [결정]. AI는 실드 문구를 밤마다 새로 쓰는 것, 어젯밤 실제 수면(HealthKit)을 보고 제안하는 것(AI 목록 때 확정). |
| iOS 접점 | DeviceActivitySchedule(시간대 실드) · ShieldConfiguration(제목·부제·버튼 2개) · 잠금화면 위젯 · HealthKit 수면 읽기 |
| 측정 | 취침 시각(HealthKit sleep), 선셋 이후 실드를 뚫은 횟수(ShieldAction 로그, 우리 기록) |
| ⚠️ | 실드는 설정 토글로 풀린다 → "뚫은 횟수"를 숨기지 않고 보여주는 쪽. 카톡은 실드 밖(허용), 알림은 사용자가 집중 모드로. |

### 1-2. 아침 — 일찍 일어나기 ("알람만으로는 부족해")

| | 내용 |
|---|---|
| 성공한 사람들의 방법 (후보) | **주말 포함 고정 기상 시각.** 알람 후 **즉시 한 동작**(물·빛·일어서기, "5초 법칙"). 알람은 손이 안 닿는 곳. **전날 밤에 아침의 첫 할 일을 정해두기**(옷·운동·첫 작업). 미라클 모닝 류의 짧은 루틴. |
| 폰이 하는 일 | **[결정 2026-11-23] 알람은 사용자가 쓰던 시계 앱 알람 그대로 — "가장 확실한 방법으로".** 우리는 울린 다음을 맡는다: 알람을 끄면 잠금화면 카드(Live Activity)에 **"오늘의 첫 한 가지 · 시작"**이 보인다(전날 밤에 정해둔 것). 기상은 폰이 아니라 **몸으로 확인**(걸음·워치·HealthKit). 우리 알람(AlarmKit, 울리는 화면에 우리 문장)은 미발화 버그가 열려 있어 사이클 1에서 제외, B가 자리 잡은 뒤 선택지로 얹는다. |
| AI가 뒤에서 | 밤에 "첫 한 가지"를 일정·운동·날씨에서 골라둠. 기상 실패가 이어지면 기상 시각을 15분 늦추고(현실 맞춤), 성공하면 유지. |
| iOS 접점 | AlarmKit(iOS 26+, 무음·집중 모드 뚫고 울림, 앱 종료돼도 울림) — 알람 화면은 시스템 템플릿이라 **제목 문장 + 버튼 2개 + 틴트색**만 우리 것. 두 번째 버튼 = "시작"(App Intent로 앱 열기), 중단 버튼은 글자만 바꿀 수 있고 못 없앰 → [research/alarmkit.md](research/alarmkit.md) · 잠금화면 Live Activity(우리가 그림) · HealthKit 수면 종료(워치, 수십 분 지연)·첫 걸음(소급 조회) |
| 측정 | 실제 기상 시각(수면 종료 또는 첫 걸음), 목표 대비 차이, 첫 한 가지 시작 여부 |
| ⚠️ | "끄기 = 시작"은 강제가 아니라 **기본 경로**(전원·볼륨 버튼·스와이프로 그냥 끌 수 있음). iOS 26.0~27.2 미발화·지연 버그가 Apple 답변 없이 남아 있음(2026-11) → 사이클 1은 AlarmKit + 시계 앱 백업 알람 [제안], 실기기로 밤새 재볼 것. |

### 1-3. 일정 — 오늘을 아주 가볍게

| | 내용 |
|---|---|
| 성공한 사람들의 방법 (후보) | **오늘 가장 중요한 일 1~3개**(MIT). 타임블록. 저녁 5분 리뷰 + 내일 3개 미리 적기. 할 일 목록은 짧게, 캘린더는 그대로. |
| 폰이 하는 일 | 홈 위젯 하나에 **오늘의 세 가지**와 다음 일정. 하나를 누르면 "시작" → Live Activity(지금 하는 일 한 줄)가 잠금화면에 상주. 끝내면 체크. 그게 전부. |
| AI가 뒤에서 | 밤에 캘린더(EventKit)·어제 못 끝낸 것·운동 계획에서 **내일의 세 가지 초안**을 만든다. 낮에 일정이 밀리면 세 가지 순서를 다시 맞춘다(위젯 갱신 시점 30초 안). |
| iOS 접점 | EventKit(캘린더 읽기) · 인터랙티브 위젯 · Live Activities · Controls(액션 버튼) |
| 측정 | 세 가지 중 끝낸 수, 세션 시간(우리 기록) |
| ⚠️ | 세 가지를 AI가 고르면 틀릴 수 있다 → 초안은 AI, 확정은 사람(밤에 10초). |

### 1-4. 운동 — 집중하고, 몇 칼로리를 썼는지

| | 내용 |
|---|---|
| 성공한 사람들의 방법 (후보) | **요일·종류가 정해진 세션**(계획이 의지를 대신). 기록(무게·시간). 점진적 과부하. 쉬는 날도 계획. |
| 폰이 하는 일 | 오늘의 운동이 "세 가지" 중 하나로 들어와 있다. "시작"을 누르면 운동 중에는 폰이 조용해지고(실드) Live Activity가 경과·칼로리를 보여준다. 끝나면 **오늘 소모 칼로리**(HealthKit 활동 에너지)가 위젯에. |
| AI가 뒤에서 | 밤에 다음 세션을 제안(이번 주 한 것·HealthKit 기록 기준). 빠진 날이 이어지면 세션을 줄여서 다시 제안. |
| iOS 접점 | HealthKit(activeEnergyBurned, workouts 읽기, 워치 자동 기록) · Live Activity · 실드 · 워치 컴플리케이션(표시·입력만) |
| 측정 | 세션 완료, 소모 칼로리(HealthKit) |
| ⚠️ | 소모 칼로리는 워치가 있어야 정확. 폰만이면 걸음 기반 추정. |

### 1-5. 식사 — 오늘 몇 칼로리를 먹었는지

| | 내용 |
|---|---|
| 성공한 사람들의 방법 (후보) | **기록하는 것 자체**가 방법(기록하면 줄어든다). 칼로리 + 단백질. 사진 한 장. 매 끼 10초. |
| 폰이 하는 일 | 위젯의 "오늘 먹은 것" 한 줄. 누르면 **사진 한 장** 또는 한 줄 입력 → 칼로리 추정 → HealthKit 섭취 칼로리에 기록. 위젯은 **소모 − 섭취**를 하루 수지로 보여준다(운동 장면과 한 숫자로 만남). |
| AI가 뒤에서 | 사진·문장 → 칼로리·단백질 추정. 밤에 내일 칼로리 예산을 운동 계획과 함께 정함. |
| iOS 접점 | HealthKit(dietaryEnergyConsumed 쓰기) · 카메라 · 위젯 · 온디바이스 Foundation Models(iPhone 15 Pro+) 또는 클라우드 비전 |
| 측정 | 기록한 끼니 수, 섭취 칼로리 |
| ⚠️ | **사진→칼로리는 사용자 수에 비례하는 AI 비용** → 브리프 ★-1 "비용 리스크 없음" 결정과 부딪힘. 온디바이스로 되는지, 아니면 텍스트 입력 + 식품 DB로 갈지 [고민 중]. |

## 2. 다섯 장면이 한 화면에서 만나는 곳 [제안]

- **홈 위젯 하나** = 하루의 현재 위치. 아침엔 "첫 한 가지", 낮엔 "세 가지 + 다음 일정", 저녁엔 "소모 − 섭취", 밤엔 "오늘 끝 · 기상 6:30". 같은 위젯이 시간에 따라 얼굴을 바꾼다.
- **실드 화면** = 방어. 밤·운동 중에만. 문구는 늘 "지금 대신 할 한 가지".
- **Live Activity** = 지금 하는 일 한 줄(운동·세션).
- **밤 10초** = 사람이 하는 유일한 입력. AI가 만든 내일(기상·첫 한 가지·세 가지·운동·칼로리 예산·취침)을 보고 확정.
- 채팅 없음. 설정 화면은 온보딩 때 한 번.

### 2-1. 사이클 1(밤 → 아침)의 하루 — 사용자 입장 [제안 2026-11-23, 창업자 "좋아"]

원칙: **설정은 한 번, 매일은 탭 두 번, 나머지는 폰이 알아서.** 앱 아이콘을 누를 일이 없는 게 목표. 카드와 위젯이 곧 앱.

**처음 한 번 (온보딩, 2분)** **[결정 2026-11-23]**
1. **하루에 몇 시간 잘 건지** ("7시간").
2. **몇 시에 일어날 건지** ("6:30").
   → 몇 시에 자야 하는지는 **계산**(11:30), 조용해지는 시각은 그 한 시간 전(10:30). 창업자: "몇 시간을 자야 하고 몇 시에 일어나는지를 만들면 몇 시에 자야 하는지가 설정이 되잖아." AI가 아니라 산수.
3. 조용히 할 앱 고르기 (애플 선택창에서 인스타·유튜브·숏폼 체크).
4. 끝. 첫 한 가지는 묻지 않는다 — AI 초안, 틀리면 밤에 고친다.
- 권한 3개(스크린타임·알림/Live Activity·건강)는 이 2분 안에 한 흐름으로. 알람은 건드리지 않는다.

**매일 (탭 두 번)**
| 시각 | 화면 | 사용자 |
|---|---|---|
| 취침 40분 전 (예: 10:50) | 잠금화면 카드: "10분 뒤 조용해져요 · 내일 첫 한 가지: 물 한 잔 마시고 창문 열기" | 탭 1 (확인). 안 해도 그대로 감 |
| 취침 1시간 전 ~ 기상 (예: 10:30~6:30) | 인스타를 열면 실드: "내일 6:30, 물 한 잔을 위해. 오늘은 끝." 버튼 "오늘 끝" / "5분만" | — (뚫은 횟수는 숨기지 않고 센다) |
| 아침 6:30 | 사용자의 시계 앱 알람 | 끔 |
| 끈 직후 | 잠금화면 카드: "물 한 잔 · 시작" | 탭 2 (시작) |
| 끝내면 | 카드 "좋은 아침" → 홈 위젯 하루 모드 | — |
| 낮 | 아무것도 없음 (사이클 1) | — |
| 다음 밤 | AI가 어젯밤 수면·오늘 아침을 보고 내일 카드를 다시 씀 (못 일어났으면 더 작게, 잘 됐으면 그대로) | — |

**사용자가 절대 안 하는 것**: 앱 열어서 보기, 통계 화면, 채팅, 설정 메뉴.
**편함을 위해 포기하는 것**: 강제. 차단은 설정에서 풀 수 있고 알람은 그냥 끌 수 있다. 대신 매일 밤 "오늘 뚫은 횟수"를 솔직하게 보여준다. 폰이 나를 가두는 게 아니라 내 편이라는 느낌은 여기서 나온다.

### 2-2. 사이클 1 화면 3장 **[결정 2026-11-23: 세 화면의 구조와 역할. 문구·톤은 나중에 — 창업자 "문구나 이런 건 나중에 설정하자"]**

| 화면 | 언제 | 누가 그리나 | 내용 |
|---|---|---|---|
| **① 실드** | 밤 10:00, 조용히 할 앱을 열었을 때 | **애플 템플릿.** 우리 것은 아이콘 1장·제목·부제·버튼 글자 2개·색 | 제목 "내일 6:30, 물 한 잔을 위해." · 부제 "오늘은 끝 · 오늘 뚫음 0" · 버튼 "오늘 끝"(우리 색) / "5분만"(글자만) |
| **② 잠금화면 카드** (Live Activity) | 밤 9:50 ~ 아침 "시작"까지 | **우리가 그림** (카드 한 칸, 전체 화면 아님) | 밤: "10분 뒤 조용해져요 · 내일 첫 한 가지: 물 한 잔 마시고 창문 열기" + "확인". 아침(알람 끈 직후): "오늘의 첫 한 가지 · 물 한 잔 마시고 창문 열기" + **"시작"**. 끝내면 "좋은 아침" |
| **③ 홈 위젯** | 낮, 홈 첫 페이지 | **우리가 그림.** 홈 첫 페이지에 이 위젯 하나만(사용자가 온보딩 때 배치) | "오늘" · ✓ 물 한 잔 마시고 창문 열기 6:41 · 기상 6:30 → 6:38 · 오늘 밤 9:50에 조용해져요 · 취침 10:30 |

- 톤·문구 [고민 중, 나중에]: 위 표의 문장들은 자리 표시용. 어두운 바탕·글자 한 줄·버튼 하나·색 하나(모래색 후보)는 제안. 숫자·그래프·점수 없음, "뚫음 횟수"만 숨기지 않는다는 것은 유지.
