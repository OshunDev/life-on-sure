# 모듈 1 — 운동

> 틀: [00-common.md](00-common.md) 3장. 상태: **초안 v2 — 디벨롭 중** (2026-11-03)
> 창업자: "운동 모듈은 내가 정말 쓰고 싶은 기능이라 더 디벨롭하자."
> 표기: [결정] · [제안] · ⚠️ 창업자가 정할 것

---

## 1. 왜 중요한가
- 몸을 움직이는 것은 체중만이 아니라 기분, 잠, 집중, 오래 사는 것과 이어진다.
- 앱의 출발점이기도 하다. 창업자는 하루 40km를 달린다. 그런데 운동만으로는 목표에 닿지 못했다. **운동 모듈은 운동을 많이 시키는 곳이 아니라, 내 움직임을 정직하게 비추는 곳**이어야 한다.

## 2. 이론과 기준

| 근거 | 내용 | 모듈에 주는 것 |
|---|---|---|
| **WHO 신체활동 권고 (2020)** | 성인은 일주일에 중강도 150~300분, 또는 고강도 75~150분. 근력 운동 주 2일. 앉아 있는 시간 줄이기 | **누구에게나 통하는 기준선: 주 150분** |
| 강도 환산 | 고강도 1분 = 중강도 2분으로 친다 | 자전거, 달리기, 걷기를 한 숫자로 합침 |
| **자기 모니터링** | 자기 활동을 기록하고 보는 것만으로 활동량이 늘어난다는 연구가 많다 | 자동 기록 + 한눈에 보기 |
| **보상 효과** | 운동한 날 "더 먹어도 된다"며 많이 먹어 운동 효과를 상쇄하는 경향 | ⚠️ 창업자의 저녁 과식과 닿아 있음. 9장 참고 |
| 손목 기기의 한계 | 워치의 심박과 시간은 비교적 정확하지만 **소모 칼로리 추정은 오차가 크다** | 칼로리는 "약"으로만 |

## 3. 무엇을 재는가

### 3-1. [결정] 오늘이 가장 중요하다
- 창업자: **"사람들은 오늘에 집중해야 한다. 오늘이 가장 중요하다."**
- 운동 모듈의 중심은 **오늘.** 이번 주, 이번 달, 올해는 뒤에서 조용히 쌓이는 것.
- 근거와 연결:
  - 내가 바꿀 수 있는 건 오늘뿐이다. 지난주는 지나갔고, 다음 달은 아직이다.
  - 가까운 하위 목표(반두라): 먼 목표보다 **오늘 할 수 있는 것**이 자기효능감을 키운다.
  - 앱 전체와 맞물림: "잘 산 하루", "오늘의 첫 걸음", Sure의 "오늘의 한마디".

### 3-2. [결정] 오늘 무엇을 볼지는 사용자가 고른다 [제안: 고르는 방식]
- 오늘의 **큰 숫자 하나 + 작은 숫자 두 개.**
- 고를 수 있는 숫자: 움직인 시간 · 거리 · 횟수 · 걸음 · 상승 고도 · 소모 칼로리(약)
  - 예) 창업자: 큰 숫자 "오늘 40.2km" · 작은 숫자 "1시간 42분", "출퇴근 2회"
  - 예) 사무직: 큰 숫자 "오늘 움직인 시간 25분" · 작은 숫자 "걸음 6,200"
  - 예) 마라톤 준비: 큰 숫자 "오늘 12km" · 작은 숫자 "평균 페이스", "심박"
- 기본값 [제안]: 오늘 움직인 시간.
- 기간(이번 주, 이번 달, 올해)은 화면 아래에 **작게, 쌓인 것으로만.** 예) "이번 달 운동한 날 18일".

### 3-3. 오늘 중심일 때 조심할 것 [제안]
- **쉬는 날이 "0"으로 보이면 안 된다.** 오늘 숫자가 0인 날은 "오늘은 쉬는 날"로 보여주고, 아래에 쌓인 것을 함께 보여준다. 오늘이 비어도 내가 쌓아온 건 사라지지 않는다.
- **매일 채워야 하는 압박이 되면 안 된다.** 오늘에 집중하는 것과 매일 해야 한다는 강박은 다르다. 연속 기록(스트릭) 압박은 두지 않는다.
- WHO 기준(주 150분)은 버리지 않는다. 기준선을 켠 사람에게는 오늘 몫으로 나눠 보여줄 수 있다 (하루 약 20분). 끄면 숫자만.

## 4. 어떻게 재는가 [제안]

| 방식 | 대상 | 수고 |
|---|---|---|
| 자동 | Apple Watch와 아이폰이 기록한 운동, 걸음, 운동 시간 (HealthKit) | 없음 |
| 자동 | 다른 운동 앱(스트라바, 가민 등)이 HealthKit에 넣은 기록 | 없음 |
| 탭 | 워치 없이 한 운동 → [운동했어요] 종류와 시간 탭 | 탭 두세 번 |
| 반복 인식 | 같은 시간, 같은 경로가 반복되면 "출퇴근 라이딩"처럼 이름을 붙여 둠 | 없음 |

## 5. 혼자서 보여주는 것 (Sure 없이, 무료) [제안]

```
운동 · 오늘

        40.2 km
   1시간 42분 · 출퇴근 2회

━━━━━━━━━━━━━━━━━━━━
이번 달 운동한 날 18일
```

- 기준을 넘으면 그냥 넘은 만큼 보여준다. 축하도, 경고도 없다. 숫자만 정직하게.
- 기준에 못 미친 주도 빨간색이 아니다. 쌓인 만큼만 보인다.

## 6. Sure에게 넘기는 것 (공통 형식)

| 칸 | 예 |
|---|---|
| 오늘 | 활동 102분 (고강도 환산) |
| 이번 주 | 150분 중 310분 |
| 평소 | 최근 4주 평균과 비슷 |
| 믿을 만함 | 시간 높음 · 칼로리 낮음 |
| 신호 | 루틴 깨짐 (출퇴근 라이딩 없는 날) / 3일 연속 고강도 / 5일째 움직임 적음 / 평소보다 훨씬 많이 소모한 날 |
| 쌓인 것 | 이번 달 운동한 날 18일 |

## 7. 목표와의 연결

이 모듈로 **자동 확인**되는 목표:
- 시간: 주 150분 움직이기
- 횟수: 주 3회 운동
- 거리: 이번 달 자전거 1,000km
- 대회: 하프 마라톤 완주 (훈련 기록 + 대회 당일 기록)
- 체중 목표의 일부 (운동 쪽 할 일)

## 8. 다른 모듈과 닿는 곳 (Sure가 이어서 해석)

| 모듈 | 닿는 지점 |
|---|---|
| 식사 | 소모와 섭취. **많이 움직인 날의 저녁**이 고비일 수 있음 (보상 효과) |
| 수면 | 잠이 부족한 날은 강도를 낮추고, 고강도 다음 날은 회복 |
| 일 | 오래 앉아 있던 날, 야근으로 운동 시간이 사라진 날 |

## 9. 하지 말 것
- **칼로리를 정확한 척하지 않는다.** 언제나 "약".
- **"운동했으니 더 드셔도 돼요"를 쉽게 말하지 않는다.** ⚠️ 브리프의 예시 "오늘 1,210kcal 태웠어요. 저녁은 800kcal까지 드셔도 괜찮아요!"가 바로 이 패턴이다. 오차 큰 숫자를 근거로 먹을 허락을 주면 창업자가 겪은 저녁 과식을 오히려 부를 수 있다. Sure의 말 방식은 다시 봐야 한다.
- **매일 운동하라고 밀지 않는다.** 연속 기록(스트릭) 압박 없음. 쉬는 날은 존중한다.
- **과한 운동을 부추기지 않는다.** 기준을 훨씬 넘는 날이 계속되면 회복을 말한다.
- **통증이나 부상은 진단하지 않는다.** 전문가에게 안내한다.

## 10. MVP 범위 [제안]
- 포함: HealthKit 읽기, 이번 주 움직인 시간, 오늘의 활동, 이번 달 운동한 날, [운동했어요] 탭, 출퇴근 같은 반복 인식
- 나중: 자체 GPS 기록 (워치 앱), 훈련 부하와 회복 (운동 마니아, 2단계), 근력 운동 상세

## 11. 페르소나별 모습

| 페르소나 | 운동 모듈이 주로 보여주는 것 |
|---|---|
| 창업자 | 출퇴근 라이딩이 자동으로 쌓임. 이미 기준을 훌쩍 넘음 → 운동보다 **식사 쪽이 고비**라는 걸 Sure가 읽을 재료 |
| 사무직 | 주 150분 중 40분. 쌓이는 만큼만 정직하게. 걷기도 포함 |
| 교대근무자 | 근무가 불규칙해도 "이번 주" 단위라 맞춰 채울 수 있음 |
| 수험생 | 운동은 보조. 공부 사이 걷기, 짧은 움직임 |
| 운동 마니아 | 핵심 숫자는 이미 넘음 → 2단계의 훈련 부하, 회복이 진짜 가치 |

## 12. 더 디벨롭할 것들 [제안 — 창업자와 함께 고를 것]

창업자가 실제로 쓰고 싶은 모습을 기준으로 깊이를 더할 후보들.

| 후보 | 내용 | 메모 |
|---|---|---|
| **직접 기록 (GPS)** | 앱과 워치에서 바로 운동 시작·종료, 경로, 속도, 심박 | 초기 아이디어 v0에 있던 것. 앞서 "읽기만"을 추천했지만, 창업자가 정말 쓰고 싶은 기능이라면 다시 볼 것 |
| **활동 상세** | 경로 지도, 구간별 속도, 심박 구간, 고도 | 라이딩·러닝 기록의 깊이 |
| **출퇴근 루틴** | 출퇴근 라이딩을 자동으로 알아보고 따로 쌓기. 날씨, 바람 | 창업자의 매일 |
| **나의 기록** | 가장 긴 거리, 가장 빠른 출근, 올해 누적 | 판정 없는 성취. 자기효능감의 재료 |
| **회복** | 심박 변이, 잠과 연결해 오늘 몸 상태 | 수면 모듈과 이어짐 (2단계) |
| **함께** | 크루 누적 거리, 같이 달린 기록 | 사람과 함께 (3-8) |

## ⚠️ 창업자가 정할 것
1. ~~핵심 숫자~~ → [결정] 오늘이 중심. 오늘의 숫자는 사용자가 고른다. 기본값만 정하면 됨 (Claude 제안: 오늘 움직인 시간).
2. **운동 기록을 직접 할지, 읽기만 할지.** MVP는 HealthKit에서 읽기만 하는 걸 추천. 기록은 애플 운동 앱이나 스트라바가 이미 잘한다.
3. **칼로리를 운동 모듈 화면에 보여줄지.** 오차가 크고 "먹어도 된다"로 이어질 수 있어, 식사와 비교할 때만 뒤에서 쓰는 방법도 있음.
