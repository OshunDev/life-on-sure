# 빈자리 검증 메모 (2026-11-23, 시장조사 세션)

## 결론 1줄
"빼기(차단)만 있고 돌려주기는 없다"는 ★-5의 전제는 틀렸다. "돌려주기"는 **earn screen time**(습관·걸음·독서·퀴즈를 하면 앱이 풀리는 거래형) 카테고리로 이미 존재하고, 2024~2026년에 iOS에서 수십 개가 생겼다. 전부 소규모·1인 개발·Screen Time API 위. 다만 "거래형(열쇠로서의 목표)"이지 "삶의 목표로 시간을 보내는 설계"는 아니다. AI 코치형도 2025년부터 여럿 등장. iPhone "덤폰 런처" 카테고리도 따로 있다(Blank Spaces 1M+).

## E. iOS 플랫폼 변화
- iOS 26: Screen Time App Limits로 앱 완전 차단 가능(이전 최소 1분). iOS 26.4: "Screen Time 접근 앱" 권한 해제에 Screen Time 비번 필요(차단앱 삭제 우회 약화). 서드파티 프레임워크(FamilyControls/ManagedSettings)는 변화 없음(단일 출처 habitdoom 블로그). 출처 techlockdown.com/articles/ios-26-screen-time-changes, ios26-update-screen-time-protected-app-permissions
- 역사: 2018 iOS 12 Screen Time 출시 전 애플이 MDM/VPN 기반 서드파티를 퇴출. API는 2021에야 공개(TechCrunch).

## F. 재해석 — Life On의 자리
1. 빈자리는 "돌려주기 자체"가 아니라 **"돌려주기의 질"**: 걸음수·체크박스 거래가 아니라 비운 시간이 **삶의 목표(일·운동·수면·관계)**로 가는 설계 + AI가 뒤에서(코치 수다 없이).
2. 첫 화면 경험(덤폰 런처)과 차단(Screen Time)과 목표(돌려주기)를 **한 제품**으로 묶은 곳은 못 찾음. 각각은 다 있음.
3. 한국어·한국 앱 생태계 맞춤은 (research-korea.md 확인) 
4. 철학·책·커뮤니티로 파는 소프트웨어 브랜드는 Light Phone/Brick(하드웨어) 쪽에만 있고, 앱은 전부 유틸리티.
5. 리스크: 카테고리가 "1인 개발 수십 개"로 붐빈다 = 진입 쉬움 = 차별은 기능이 아니라 경험·브랜드·유지율.
